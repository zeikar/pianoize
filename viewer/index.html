How an arrangement is made

Every step runs on your own machine. The pianoize plugin for Claude Code runs its own copy of pianoize, which needs uv and git; preparing a song also needs FFmpeg, and rendering needs FluidSynth and a piano SoundFont.

  1. Install

    Add the plugin to Claude Code.

    /plugin marketplace add zeikar/pianoize
/plugin install pianoize@pianoize

  2. Prepare

    Ask Claude Code to prepare a song from a YouTube link or an audio file. Its prepare-song skill installs the models once, transcribes the recording, takes the melody and generates a piano cover.

    prepare this song: https://youtu.be/…

  3. Arrange

    Ask it to arrange the song. Its arrange-cover skill writes a two-hand score bar by bar; pianoize builds it into MIDI, checks that it is playable, renders arranged.wav for you to listen to and exports arranged.json for this page.

    arrange this song for two hands

  4. Play

    Drop the two files from the song's folder on the keyboard above. The same MIDI renders to an MP4 with render-video and a cards file.

    work/<song>/arranged.json
work/<song>/arranged.wav
